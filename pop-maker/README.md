# POPキャッチコピー作成

売り場のPOPに使う短いキャッチコピーの候補を出すツールです。
サーバーやAIは使わず、あらかじめ用意した「文のひな形」に商品名・特徴を当てはめて作ります。
ネットにつながっていなくても動き、費用もかかりません。

公開URL: https://respect00886-byte.github.io/claude-code/pop-maker/

## 使い方

1. 商品名を入れる（必須）
2. 特徴を3つまで入れる。商品の種類（ペン・ノート・シール・キャラクターグッズなど）を選ぶと候補が出て、タップで入れられます。手入力もできます
3. 必要なら「お知らせ」（数量限定／おひとり様1点まで など）を選ぶ。POPの上に赤い帯で入ります
4. 「だれに向けて？」（子ども／大人／ファン向け／プレゼント）と「雰囲気」（元気・にぎやか／やさしい／上品・落ち着き）を選ぶ
5. 「候補を出す」を押す。押すたびに別の候補が出ます
6. 気に入った文は「コピー」で他のアプリに貼り付け、または「POPで表示」でサイズと背景（シンプル／水玉／星／ノート罫線／ストライプ／二重フレーム）を選び、「印刷」か「画像で保存」（PNG）。スマホでは共有メニューの「画像を保存」で写真に入ります

### サイズ

| サイズ | 使いみち | 印刷すると |
| --- | --- | --- |
| A4横・A4縦 | 売り場の大きなPOP | A4用紙いっぱい |
| A5横・A5縦 | 中くらいのPOP | A4用紙に実物大（切って使う） |
| 名刺（棚用） | 棚に貼る小さなPOP（91×55mm） | A4用紙に実物大（切って使う） |
| 正方形（SNS） | SNS投稿用 | A4用紙に15cm四方 |

文字の大きさと配置はサイズに合わせて自動で整います。保存される画像はA4で約300dpi相当の細かさで、拡大印刷しても文字がぼやけにくくなっています。

前回の入力内容は、その端末のブラウザにだけ残ります。

## 文のひな形を増やしたいとき

`src/data/templates.ts` に1行ずつ書かれています。`{商品}` が商品名、`{特徴}` と `{特徴の}` が入力した特徴に置き換わります（使い分けはファイル先頭の説明を参照）。
25文字を超える文は、候補の後ろに回されます（`src/lib/generate.ts` の `MAX_LENGTH`）。

## 特徴の候補・お知らせ・背景を増やしたいとき

- 特徴の候補：`src/data/featureSuggestions.ts`（「〜い」「〜る」で終わる言葉か名詞にすると文が自然になります）
- お知らせ：`src/data/notices.ts`
- 背景の色：`src/data/backgrounds.ts`（模様の描き方は `src/lib/drawPop.ts`）
- サイズ：`src/data/sizes.ts`
