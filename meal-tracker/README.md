# 毎日の食事管理アプリ (meal-tracker)

カロリーと3大栄養素(PFC: たんぱく質・脂質・炭水化物)を記録・管理できる、シンプルな食事管理アプリです。
データは端末のブラウザ内(localStorage)に保存され、サーバーやログインは不要です。

## 主な機能

- **食事記録**: 日付・区分(朝食/昼食/夕食/間食)・内容・カロリー・PFCを記録。カロリー/PFCはすべて任意項目で、未入力でも記録可能
- **メニュー検索でワンタップ記録**: 代表的なコンビニ・チェーン店メニュー(おにぎり、ビッグマック、牛丼など)を名前で検索し、タップするだけで確認画面なしに即記録。区分は現在時刻から自動推測(例: 正午前後なら昼食)
- **お気に入りメニュー**: よく食べる自炊・外食メニューを自分で登録しておくと、次回から同様にワンタップで記録可能。既存の記録からも「お気に入りに保存」できる
- **当日の合計と目標管理**: カロリー・たんぱく質・脂質・炭水化物それぞれに1日の目標値を任意で設定し、残り/超過を表示
- **履歴**: 日付を選んで過去の記録・合計を閲覧
- **編集/削除**: 記録済みの内容はあとから自由に修正・削除可能

## 技術スタック

React / TypeScript / Vite。バックエンドなし、外部APIなし、localStorageのみでデータを保持するシンプルな構成です。

## 使い方

このディレクトリ(`meal-tracker/`)に移動してから実行してください。

```bash
cd meal-tracker
npm install
npm run dev       # 開発サーバー (http://localhost:5173)
npm run build     # 本番ビルド (dist/)
npm run preview   # ビルド結果の確認
```

同じWi-Fiのスマホから試す場合は `npm run dev -- --host` で起動し、表示されたURLにアクセスしてください。

## データについて

記録・お気に入り・目標設定は、その端末・そのブラウザにのみ保存されます(サーバー送信なし)。ブラウザのデータを消去すると記録も失われるため、機種変更やブラウザの変更時は注意してください。

## ディレクトリ構成

```
src/
  types.ts          型定義(MealEntry, AppSettings, MenuItem)
  data/
    starterMenu.ts   同梱の代表的コンビニ/チェーン店メニュー
  lib/
    storage.ts       localStorage読み書き
    date.ts          日付処理、区分の自動推測
    calories.ts       カロリー・PFCの集計、目標との差分計算
    search.ts         メニュー検索
  components/
    MealForm.tsx       記録の追加/編集フォーム
    MealList.tsx        記録一覧
    DailySummary.tsx     当日合計・目標表示
    HistoryView.tsx       履歴(日付ごとの閲覧)
    GoalSettings.tsx       目標値の設定
    MenuSearch.tsx          メニュー検索・ワンタップ記録・お気に入り登録
```
