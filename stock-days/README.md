# 在庫もつ日数

商品の在庫が「あと何日もつか」「いつまでに発注すればよいか」を計算するページです。
サーバーは使わず、入力した内容はこの端末のブラウザ内にだけ保存されます。

公開URL: https://respect00886-byte.github.io/claude-code/stock-days/

## 使い方

1. 商品名と今の在庫数を入れる
2. 売れる数を入れる
   - **期間の合計で**：「過去7日で21個」のように入れると、1日3個として計算します
   - **1日の数で**：「1日3個」を直接入れます
3. （任意）発注してから届くまでの日数を入れると、「○月○日までに発注」も表示します
4. 「一覧に追加」を押すと、もうすぐ無くなる順に並びます

在庫を数えた日から日がたつと、そのぶん残り日数を自動で減らします。
在庫を数え直したら「編集・数え直し」で在庫数を直してください（数えた日も今日になります）。

## 色分け

| 色 | 目安 |
| --- | --- |
| 赤（急いで） | 残り3日以下、または発注日を過ぎた・今日が発注日 |
| 黄（注意） | 残り7日以下、または発注日まで3日以内 |
| 緑（余裕あり） | それ以外 |

残り日数は少なめに見るため、小数点以下は切り捨てています（2.7日分 → あと2日）。

## 開発

```bash
cd stock-days && npm install && npm run dev
```
