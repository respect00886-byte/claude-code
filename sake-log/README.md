# 日本酒ログ（sake-log）

飲んだ日本酒を、星5段階とワンタップのコメントで記録して見返すアプリです。

公開URL: https://respect00886-byte.github.io/claude-code/sake-log/

## できること

- **記録**：名前・星（必須）、味や香りのコメント（タップで選ぶ）、写真
  - 「くわしく」を開くと、種類・蔵元・産地・お店（飲んだ店／買った店）・値段・飲んだ日も入れられます
  - お店は前回の店が最初から入ります。くわしい項目が空の記録には、一覧に「あとで追記」と出ます
- **マイコメント**：定番にない言葉（例：「桃っぽい」）を自分で追加できます
- **見返す**：名前・蔵元・産地・お店で検索、新しい順／★の多い順、コメントで絞り込み、写真の一覧表示
- **削除**：消したあと数秒は「元に戻す」が押せます
- **バックアップ**：設定画面から、写真も含めて1つのファイル（zip）に書き出し・読み込みできます

## データの保存について

記録はこのスマホのブラウザの中だけに保存されます（サーバーには送りません）。
iPhone は、しばらく開かないとデータを消すことがあるため、Safari の「ホーム画面に追加」から使うのがおすすめです。
機種変更に備えて、ときどきバックアップを書き出してください。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト（検索・絞り込み・バックアップ）
npm run build    # 型チェック + ビルド
```
