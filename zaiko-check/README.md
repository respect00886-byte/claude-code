# 在庫もちチェッカー（zaiko-check）

売り場の商品ごとに「今の在庫があと何日もつか」を確認するツールです。スマホでの利用を想定しています。

公開URL: https://respect00886-byte.github.io/claude-code/zaiko-check/

## 使い方

1. 「商品を追加」に商品名・在庫数・1日に売れる数を入れて「追加する」
2. 一覧は、もちが短い順に並びます（在庫数 ÷ 1日に売れる数 ＝ あと何日）
   - 赤「発注」… 7日以下　黄「注意」… 14日以下　緑「大丈夫」… それ以上
   - 基準の日数は画面下の「色分けの基準」で変えられます
3. 商品をタップすると、在庫数を ±1 / ±10 で直したり、削除したりできます

- 売れる数が 0 の商品は「売れていない」と表示され、一覧の最後に並びます。
- 「◯/◯ごろに切れる」は、最後に数を直した日から数えた目安です。
- データはこの端末のブラウザの中だけに保存されます（他の端末とは共有されません）。

## 開発

```bash
cd zaiko-check && npm install && npm run dev
```
