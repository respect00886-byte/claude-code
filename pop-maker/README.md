# POP作成

売り場のPOPを作るツールです。見出し（大きい文字）と補足文（小さい文字）を自分で入力し、
そのまま印刷・画像保存できます。サーバーやAIは使わず、ネットにつながっていなくても動き、費用もかかりません。

公開URL: https://respect00886-byte.github.io/claude-code/pop-maker/

## 使い方

1. 「見出し」と「補足文」を入力する。改行した位置でPOPの行も変わります。文字の大きさは文字数に合わせて自動で変わります
2. 言い回しに迷ったら「言い回しから選ぶ」を使う
   - **定番の言い回し**：「おすすめ」「お詫び（欠品・入荷待ち・値上げなど）」「お知らせ」を選ぶと例が出ます。タップで入力欄に入ります（今の文と入れ替わります。◯月◯日 などは入れたあとで書き換えてください）
   - **マイフレーズ**：入力欄の下の「☆ この文をマイフレーズに登録」で、よく使う文を登録できます。タップで入力欄へ、×で削除
3. 必要なら「お知らせ」（数量限定／おひとり様1点まで など）を選ぶ。POPの上に赤い帯で入ります
4. プレビューを確認し、「仕上げ・印刷・保存へ」でサイズ・背景・文字の色を選び、「印刷」か「画像で保存」（PNG）。スマホでは共有メニューの「画像を保存」で写真に入ります
   - 背景（明るい）：シンプル／水玉／星／ノート罫線／ストライプ／二重フレーム
   - 背景（おとなしい・お詫びやお知らせ向け）：白・細枠／かしこまり（細い二重線）／薄グレー／紺の細枠／ベージュ
   - 文字の色：見出しと補足文それぞれ、標準（背景に合わせた色）／黒／紺／赤／緑／茶／ピンク／オレンジ から選べます

### サブ機能：自動で候補を出す

画面下の「自動で候補を出す（サブ機能）」を開くと、商品名・特徴・対象・雰囲気から見出しの候補を出せます。
「見出しに使う」を押すと見出し欄に入ります（文に商品名が入っていない候補は、補足文が空なら商品名を補足文に入れます）。

### サイズ

| サイズ | 使いみち | 印刷すると |
| --- | --- | --- |
| A4横・A4縦 | 売り場の大きなPOP | A4用紙いっぱい |
| A5横・A5縦 | 中くらいのPOP | A4用紙に実物大（切って使う） |
| 名刺（棚用） | 棚に貼る小さなPOP（91×55mm） | A4用紙に実物大（切って使う） |
| 正方形（SNS） | SNS投稿用 | A4用紙に15cm四方 |

文字の大きさと配置はサイズに合わせて自動で整います。保存される画像はA4で約300dpi相当の細かさで、拡大印刷しても文字がぼやけにくくなっています。

前回の入力内容とマイフレーズは、その端末のブラウザにだけ残ります（別のスマホやパソコンとは共有されません）。

## 自動生成の文のひな形を増やしたいとき

`src/data/templates.ts` に1行ずつ書かれています。`{商品}` が商品名、`{特徴}` と `{特徴の}` が入力した特徴に置き換わります（使い分けはファイル先頭の説明を参照）。
`/` はPOPで改行してよい位置です。言葉の途中で改行されないよう、文節の区切り（「〜が/」「〜で/」など）に入れてください（画面やコピーには出ません）。
25文字を超える文は、候補の後ろに回されます（`src/lib/generate.ts` の `MAX_LENGTH`）。

## 定番の言い回し・特徴の候補・お知らせ・背景を増やしたいとき

- 定番の言い回し：`src/data/phrases.ts`（用途ごとに「見出し向き」「補足文向き」を分けて書きます）
- 特徴の候補：`src/data/featureSuggestions.ts`（「〜い」「〜る」で終わる言葉か名詞にすると文が自然になります）
- お知らせ：`src/data/notices.ts`
- 背景の色：`src/data/backgrounds.ts`（模様の描き方は `src/lib/drawPop.ts`。`calm: true` を付けると「おとなしい」の段に出ます）
- 文字の色：`src/data/textColors.ts`
- サイズ：`src/data/sizes.ts`
