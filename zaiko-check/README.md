# 在庫もちチェッカー（zaiko-check）

売り場の商品の在庫が「あと何日もつか」「納品まで足りるか」をすぐ確認できるアプリです。

## 使い方

1. 商品名・現在の在庫数・1日に売れる数・納品までの日数を入力します。
2. 入力するとすぐに結果が表示されます。
   - あと何日もつか（小数は切り捨て）
   - 在庫が切れる日（今日から数えた日付）
   - 納品日までに足りなくなるかどうか（足りない場合は赤色で、不足する日数と個数の目安を表示）

入力した内容はどこにも保存されません。

## 開発

```bash
npm install
npm run dev    # 開発サーバー
npm run build  # 型チェック + ビルド
```
