# POPキャッチコピー作成

売り場のPOPに使う短いキャッチコピーの候補を出すツールです。
サーバーやAIは使わず、あらかじめ用意した「文のひな形」に商品名・特徴を当てはめて作ります。
ネットにつながっていなくても動き、費用もかかりません。

公開URL: https://respect00886-byte.github.io/claude-code/pop-maker/

## 使い方

1. 商品名を入れる（必須）
2. 特徴を3つまで入れる（例：ラメ入り、消せる、限定デザイン）
3. 「だれに向けて？」（子ども／大人／ファン向け／プレゼント）と「雰囲気」（元気・にぎやか／やさしい／上品・落ち着き）を選ぶ
4. 「候補を出す」を押す。押すたびに別の候補が出ます
5. 気に入った文は「コピー」で他のアプリに貼り付け、または「POPで表示」→「印刷」（A4横）

前回の入力内容は、その端末のブラウザにだけ残ります。

## 文のひな形を増やしたいとき

`src/data/templates.ts` に1行ずつ書かれています。`{商品}` が商品名、`{特徴}` と `{特徴の}` が入力した特徴に置き換わります（使い分けはファイル先頭の説明を参照）。
25文字を超える文は、候補の後ろに回されます（`src/lib/generate.ts` の `MAX_LENGTH`）。
