# GymLog — 筋トレ・体重記録アプリ

スマホで片手でサッと記録できる、筋トレと体重の管理アプリ（PWA）です。
データは端末のブラウザ内（IndexedDB）に保存され、サーバーやログインは不要です。

## 主な機能

- **筋トレ記録**：部位のチップ → 種目をタップ → 重量・回数・セット数を大きな ± ボタンで入力
  - **「＋1セット」ボタンで直前と同じ内容を1タップ記録**（セットごとに記録する使い方向け）
  - 前回の記録を初期値に自動セット／長押しで連続増減／数字をタップして直接入力も可
  - 重量の刻みは種目ごとに設定可能（初期値：バーベル 2.5kg／ダンベル 1kg／マシン 5kg）
  - **種目ごとに重量の入力単位（kg / lb）を選択可能**。lb 表記のマシンなどは lb で入力すると kg に換算して記録・表示（元の lb も併記）
  - 懸垂・ディップスなどの**自重種目**に対応（加重は任意、「自重」「自重+10kg」と表示）
  - 記録済みの行をタップすると修正・削除。まとめたセットのうち1セットだけ直すことも可
  - 記録・変更・削除のあとは「元に戻す」が可能
  - 日付を切り替えて過去の日の記録も入力可能（過去日の表示中は目立つ帯で表示）
  - その日の**部位ごとのボリューム**（例：胸 2,600kg・背中 1,500kg＋自重20回）を上部に表示
- **ルーティン**：「前回のメニューをコピー」やルーティンの読み込みで、その日の予定（目標の重量・回数・セット数）を作成。「＋1セット」で消化し、進み具合（例：2/3）を表示。その日のメニューに名前を付けてルーティンとして保存可能
- **メモ**：種目ごとのメモと、その日全体のメモ。次回その種目を記録するときに前回のメモを表示
- **体重記録**：±0.1kg（lb 表示時は ±0.2lb）ステッパー、体脂肪率（任意）、1 か月〜全期間の推移グラフ
- **履歴**：日付ごとの一覧とメモ（タップでその日の記録を編集）
- **グラフ**：「種目別」で最大重量・推定 1RM の推移と自己ベスト（自重種目は回数）、「部位別」で胸・背中などの部位ごとのボリュームとセット数の推移
- **設定**：重量の単位（kg / lb）、ルーティンの名前変更・削除、種目の追加・名称変更・種類（重量／自重）・重量の刻み・非表示、JSON バックアップ／復元、データ保護（永続ストレージ）の状態表示
- ライト／ダークモード対応、オフライン動作、ホーム画面に追加してアプリとして利用可能

## 技術スタック

Vite / React 19 / TypeScript / Tailwind CSS v4 / Dexie.js (IndexedDB) / React Router / Recharts / vite-plugin-pwa / Vitest

## 使い方

```bash
npm install
npm run dev       # 開発サーバー (http://localhost:5173)
npm run build     # 本番ビルド (dist/)
npm run preview   # ビルド結果の確認
npm test          # ユニットテスト
npm run lint      # ESLint
```

同じ Wi-Fi のスマホから試す場合は `npm run dev -- --host` で起動し、表示された URL にアクセスしてください。

### 公開（GitHub Pages）

`main` に変更が入るたびに、GitHub Actions（`.github/workflows/deploy.yml`）が検査・テスト・ビルドを行い、GitHub Pages に自動で公開します。

最初の1回だけ、GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** に切り替えてください。公開先は次のアドレスです。

https://respect00886-byte.github.io/claude-code/

手動で公開し直したいときは、**Actions → Deploy to GitHub Pages → Run workflow** から実行できます。

### スマホのホーム画面に追加する

上のアドレスをスマホで開いて、

- **iPhone (Safari)**：共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**：メニュー →「ホーム画面に追加」／「アプリをインストール」

## データについて

記録はその端末・そのブラウザにだけ保存されます（重量は常に kg で保存し、lb は表示と入力のときに換算します）。機種変更やブラウザのデータ削除に備えて、
「設定 → バックアップ → 書き出し」で定期的に JSON を保存しておいてください。「復元」で読み込めます。

## ディレクトリ構成

```
src/
  db/          Dexie のスキーマ・初期種目・データ操作
  lib/         集計 (推定1RM・ボリューム)、バックアップ、日付ユーティリティ
  components/  ステッパー、ボトムシート、種目ピッカー、グラフ等
  pages/       記録 / 履歴 / 体重 / グラフ / 設定
```
